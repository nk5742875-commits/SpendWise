About SpendWise

A beginner-friendly multi-page expense tracker built with pure HTML, CSS and JavaScript.

🧱

Multi-page structure

Every main feature has its own HTML page so the project is easy to explain in a viva or presentation.

🎨

Shared styling

All pages use one style.css, creating a consistent responsive design.

⚙️

Shared logic

One script.js handles login simulation, localStorage, expenses, filters, budget and navigation.

How the pages connect

The navbar uses normal HTML links such as href="dashboard.html". When you add an expense, JavaScript stores it in localStorage. Dashboard, History and Status read the same saved data, so changes are visible across the full project without a backend.
