# SpendWise - Multi-Page Expense Tracker

A complete beginner-friendly frontend project made with **HTML, CSS and JavaScript**.

## Project structure

```text
SpendWise/
├── index.html          # Home page
├── login.html          # Demo login page
├── dashboard.html      # Monthly summary dashboard
├── add-expense.html    # Add expense form
├── history.html        # Search/filter/delete expenses
├── status.html         # Budget and category status
├── about.html          # Project explanation
├── contact.html        # Demo contact form
├── style.css           # Shared styling for all pages
├── script.js           # Shared JavaScript logic
└── PROMPT.md           # Reusable project-generation prompt
```

## How to run in VS Code

1. Extract the ZIP.
2. Open the **SpendWise** folder in VS Code.
3. Install the **Live Server** extension if needed.
4. Right-click `index.html` → **Open with Live Server**.
5. Click **Login**.
6. Enter any valid email and any password.
7. Add expenses and check Dashboard, History and Status.

## Features

- Responsive navigation across all pages
- Demo login/session using localStorage
- Add expense (title, amount, category, date, note)
- Dashboard monthly totals
- Expense history with search and filters
- Delete expense
- Monthly budget management
- Category-wise spending summary
- Responsive mobile layout
- No backend or database required

## Data storage

This demo uses browser `localStorage`. Clearing browser site data will reset saved expenses.
